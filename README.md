# Interactive Projects

A collection of interactive applications and web experiences developed using Python and modern frontend technologies. This repository demonstrates the implementation of application logic, user interaction, task management, and immersive web design.

## Projects

### 1. Guess The Number
An interactive number-guessing game in which users attempt to identify a randomly generated number through successive guesses.

**Key Features**
- Random number generation
- Interactive user input
- Real-time feedback
- Simple and intuitive interface

**Tech Stack:** Python, Streamlit

---

### 2. To-Do List
A task management application designed to simplify daily planning and activity tracking through an interactive interface.

**Key Features**
- Task creation and management
- Task organisation
- Interactive user interface
- Streamlit-based application experience

**Tech Stack:** Python, Streamlit

---

### 3. TaskSpace — 3D To-Do Web Experience
An immersive reinterpretation of a conventional task management application, combining productivity functionality with modern 3D web technologies and visual design.

**Key Features**
- Interactive 3D visual elements
- Mouse-responsive 3D sculpture
- Contemporary glass-inspired interface
- Task creation, completion and deletion
- Dynamic progress tracking
- Responsive web layout
- Animated visual interactions

**Tech Stack:** React, JavaScript, Vite, Three.js,
